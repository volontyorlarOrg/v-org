# Organisation portal documentation

## Personal data and legal notices

The sign-in page links to the Privacy Policy and Terms on the marketing site
when `NEXT_PUBLIC_MARKETING_URL` is set (for example `https://volontyorlar.uz`);
while it is blank the links are hidden. The policy text lives in `../v-web`.
Organisations see applicant data only for their own opportunities; the
volunteer is notified when an application reaches them. See
[consent and data-request operations](../../v-backend/docs/operations/DATA_RIGHTS_AND_CONSENT.md).
